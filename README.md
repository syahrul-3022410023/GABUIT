# Buket Untuk Kamu

Website sederhana berisi satu buket bunga interaktif. Saat buket diambil, muncul efek kecil dan pesan manis untuk menceriakan hari.

## Fitur

- Satu buket bunga sebagai fokus utama.
- Efek animasi saat buket diambil.
- Pesan singkat yang muncul setelah interaksi.
- Tampilan responsif untuk desktop dan mobile.

## Struktur File

```text
.
|-- index.html
|-- style.css
|-- script.js
`-- README.md
```

## Cara Menjalankan

Buka `index.html` langsung di browser, atau publish repository ini melalui GitHub Pages.
